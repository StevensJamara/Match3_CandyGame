This is a 2D match-3 puzzle game developed using Unity, inspired by popular casual mobile games like Candy Crush.

The game focuses on core puzzle mechanics, smooth player interaction, and performance optimization for mobile devices.

🧩 Core Features:
- Tile swapping system with input handling. 
- Match detection (horizontal & vertical).  
- Cascading system (matched tiles disappear and new tiles fall down).  
- Automatic board refill after matches. 
- Grid-based game logic for stable gameplay.
  
⚙️ Technical Highlights:
- Built using Unity (2D) and C#.  
- Implemented grid system for board management.
- Developed matching algorithm for detecting valid matches.  
- Managed game state and tile behaviors efficiently.  
- Optimized gameplay for smooth performance on mobile devices.
  
📱 Mobile Optimization:
- Designed for touch input interaction.  
- Ensured responsive gameplay and smooth animations.  
- Focused on performance for mobile platforms.
